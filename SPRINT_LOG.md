# FocusLounge Sprint Log

## 2026-03-30 — Focus Journal
**Description:** A post-pomodoro quick-capture note system with a searchable journal view. After every pomodoro completes, a compact `JournalPrompt` card slides in from the bottom-right with a 30-second SVG countdown ring, the session number, and (if set) the current task name. Users type what they accomplished and hit Enter or "Save note →"; pressing Skip or Escape (or letting the timer expire) dismisses without saving. Notes are persisted to `localStorage` under `focusflow_journal` (newest-first, capped at 200 entries). The `FocusJournal` modal (triggered by pressing `J` or clicking the journal icon badge at bottom-right) groups all entries by day (Today / Yesterday / weekday label) with a left-accent indigo border per entry, showing timestamp, optional task badge, session number, and the note text. When more than 3 entries exist a search bar appears that filters by note text or task name in real-time with a "No matching notes" empty state. A `JournalBadge` button gains a pulsing indigo notification dot whenever a new entry was just saved. The badge dot clears when the journal is opened. All colours use CSS variables — no hardcoded white/black.

## 2026-03-30 — Smart Task Reordering
**Description:** A glassmorphic "Smart Sort" modal (triggered by pressing `N` or clicking the sort badge at bottom-right, bottom: 22rem) that analyses today's task list and suggests an optimal order based on a cognitive energy model keyed to the current time of day. Six energy phases are defined: Dawn (5–7 am, ease-in), Morning (7 am–12 pm, peak focus), Midday (12–2 pm, energy dip), Afternoon (2–6 pm, second wind), Evening (6–10 pm, wind-down), and Night (10 pm+, rest mode). Each phase gets its own accent colour and description. A live energy-meter bar shows the current level with a glowing fill. Tasks are scored by three factors: in-progress momentum (csec > 0 bubbles to the top at +40), priority (high=+30, medium=+15), and an energy-match bonus that rewards longer/harder tasks during peak phases and shorter tasks during low-energy phases. Each task card in the suggested list shows its rank bubble, title, estimated-pomo pill, and a colour-coded reason badge (⚡ In progress, 🔥 Priority + peak energy, 💪 Deep work match, ⚡ Quick win, 📋 On track, 🌿 Light task). If the current order already matches the suggestion, an "✓ Already optimal" chip is shown and the Apply button is replaced with "Keep current order". Pressing Apply dispatches `updateTodaysTasks` to bulk-reorder the Redux task IDs, shows a "✓ Tasks reordered!" confirmation, then auto-closes after 900 ms. All colours use CSS variables — no hardcoded white/black.

## 2026-03-30 — Daily Focus Timeline
**Description:** A glassmorphic "Daily Focus Timeline" modal (triggered by pressing `T` or clicking the timeline badge at bottom-right, bottom: 18.5rem) that renders a vertical chronological timeline of every pomodoro session completed today. Each session node is colour-coded by time-of-day context: Dawn (pink), Morning (blue), Midday (amber), Afternoon (orange), Evening (violet), Night (indigo). A flow-streak algorithm detects when 3+ sessions fall within 90 minutes of each other and highlights those nodes with a glowing outer ring and a 🔥 Flow badge, while a lit connector line links the streak nodes. Each session card shows the start time, time-of-day label badge, duration, and optional task name (📌). A pulsing cyan "Now · HH:MM am/pm" live marker updates every 30 s. A stats strip at the top surfaces: session count, total focus time, longest consecutive streak, and whether a flow state was reached. Empty-state copy encourages the first pomodoro. `recordFocusSession()` is called from homepage alongside `recordPomoCompletion()` on each pomo completion; data is persisted in localStorage under `focusflow_sessions`.

Channels: Rain (white noise + lowpass), Ocean (brown noise + lowpass tremolo), Focus Noise (pure white noise), Binaural Focus (200 Hz + 208 Hz stereo oscillators → 8 Hz alpha-wave beat), Forest (bandpass white noise at 700 Hz), and Café (bandpass brown noise at 1800 Hz). Each channel has an on/off toggle, per-channel volume slider with dynamic thumb colour, and a live on/off indicator dot. An animated 20-bar rainbow EQ visualizer dances in sync with audio playback using CSS keyframes with pre-computed per-bar delays and heights. An "X playing" pill badge counts active channels, and the EQ label switches between "▶ Playing" and "■ Stopped".

## 2026-04-03 — Distraction Tally
**Description:** A two-part feature for tracking and analysing focus interruptions. A floating ✗ button (bottom-left, fixed) lets users tap once each time they are distracted during a pomodoro — each tap increments a live count badge and pops open a 5-option category picker (Phone, Thoughts, Colleague, Notification, Other) that auto-dismisses after 3 s. Selecting a category tags the distraction so patterns surface later; "Skip" closes the popover without categorising. When a pomodoro completes the current session's count + categories are persisted to localStorage under `focusflow_distractions` keyed by YYYY-MM-DD, then the counter resets for the next session. The analytics panel (press `D` or click the ✗ badge at bottom-right) surfaces: a stats strip with today's total, weekly total, avg distractions/session, and best session count; a 7-day bar chart with today highlighted in a deeper red; a per-session quality breakdown (Perfect / Good / Fair / Tough) with mini progress bars; a category breakdown showing ranked distraction sources with horizontal bars; and a contextual insight tip that adapts copy based on avg distractions per session. An empty state with a ✓ icon encourages first use. All colours use CSS variables — no hardcoded white/black.
